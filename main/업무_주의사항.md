백엔드 규칙은 앞서 분석시 사용한 코드중에 확정버전만 쓴다

- CMD에서 `--directory` 뒤에 제공할 폴더 경로 지정:
python -m http.server 3000 --directory "\option2"
- 현재 폴더가 `option2`라면:
python -m http.server 3000
파일명이 index.html이 아니면 주소 뒤에 실제 파일명을 붙이면 됨:
    - `http://localhost:3000/data_viewer_offline.html`
