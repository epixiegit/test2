- `--bug-demo` 실행: **실패 1개, 종료코드 1**.

- 이 실패는 오류를 찾아내는 학습용 사례이며, 정상 코드가 통과했다는 기록으로 바꾸지 않음.
- 증거: [실패 요약](evidence/automated/bug_summary.json), [실패 원문 로그](evidence/automated/bug_log.txt).

## 3. 실제 브라우저 검사: PASS

Playwright로 실행 중인 로컬 서버에 접속해 아래 9개 흐름 확인.

1. 최초 조회: 승인 5건·35,000원·3개 부서.
2. 응답을 일부러 늦춤: 이전 숫자·표가 지워지고 다운로드가 비활성화됨.
3. 품질 선택: 1건·5,000원.
4. 품질 CSV 실제 다운로드: 저장된 파일을 다시 열어 `품질,1,5000`과 UTF-8 BOM 확인.
5. 없는 부서 선택: 0건·0원·빈 결과 안내.
6. 네트워크 요청 강제 실패: 오류 안내, 이전 숫자·표 제거.
7. 요청 차단 해제 후 다시 조회: 정상 복구.
8. 페이지 새로고침: 기본 전체 결과 표시.
9. 화면 너비 390px: 가로 넘침 없음.

- 네트워크 실패는 Playwright의 요청 차단으로 모의 재현. 서버 프로세스를 실제로 중단한 검사는 아님.
- 처리되지 않은 JavaScript 오류 0개. 의도적인 요청 실패로 생긴 네트워크 오류는 별도 구분.
- 저장된 PC·모바일 화면 이미지도 직접 열어 글자·표·버튼 배치 확인.
- 증거: [브라우저 검사 기록](evidence/browser/results.json), [실제 다운로드 파일](evidence/browser/quality_download.csv), [PC 화면](evidence/browser/desktop.png), [모바일 화면](evidence/browser/mobile.png).

## 4. 실행되지 않은 검사를 통과로 처리하지 않는지 확인

- 검사 0개인 상황을 모의 실행: `INCOMPLETE`, 종료코드 2 확인.
- 건너뛴 검사만 있는 상황을 모의 실행: `INCOMPLETE`, 종료코드 2 확인.
- 추가 확인: Python 문법 검사, BAT의 ASCII·CRLF 형식, 다운로드 CSV 재읽기.
- 증거: [추가 검사 결과](evidence/automated/additional_checks.json).

## 5. 환경 제약과 확인하지 않은 범위

- 최초 제한된 샌드박스에서는 API의 로컬 연결이 `WinError 10013`으로 차단됨. 분석 검사는 통과했으나 API 검사를 통과로 세지 않음.
- 로컬 연결이 허용된 실행 환경에서 **동일한 내장 Python과 테스트를 다시 실행**해 통과 확인. 테스트를 삭제하거나 건너뛰지 않음.
- 시험 당일의 네트워크·권한·포트 미리보기는 이 PC와 다를 수 있으므로 실제 환경에서 재검증 필요.
- 이 예제는 표준 라이브러리 서버. **FastAPI·React·DB·로그인·권한 분리·동시 접속 부하·운영 배포는 검증하지 않음**.
- 관련 기능이 실제 과제에 있다면 해당 프로젝트에서 검증 범위를 추가. 이 예제의 PASS를 실제 과제의 PASS로 복사하지 않기.
