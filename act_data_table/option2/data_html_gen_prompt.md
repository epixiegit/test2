현재상황 : {원본테이블경로}   있는 파일들에 대해, 추가적인 새로운 작업 파일들을 만든게{분석테이블경로}에 있으며, 폴더구조는 유지했다. 원본에 대응하는 추가 작업파일이 없으면 ‘추가 분석 결과 없음’으로 표시한다. 해당 원본은 사이드바에 유지하고 원본 탭만 제공한다.

{원본테이블경로}  , {분석테이블경로} 관련
원본 경로를 기준으로 한 상대 경로를 사용해 결과를 연결한다. 원본 파일의 확장자까지 포함한 이름의 결과 폴더를 찾고, 그 아래 모든 파일을 재귀적으로 탐색한다. 파일명만 같고 상대 경로가 다른 결과를 임의로 연결하지 않는다.

예시

{원본테이블경로}  /하위폴더/A.csv
→ {분석테이블경로}/하위폴더/A.csv/추가 작업파일들
추가 작업파일은 해당 원본파일명 폴더의 모든 하위 폴더까지
재귀적으로 탐색하고, 발견한 파일들을 각각 별도 탭으로 표시한다.


사이드바에는 {원본테이블경로}의 전체 폴더·파일 구조를 표시한다.
거기서 파일을 누르면 우측 메인페이지에서는

1. 원본데이터를 보여주는탭 + 해당원본관련 추가 작업파일들을 보여주는 탭(여러개일수도) 으로 구성한다.  
    각 탭을 누르면 해당 내용을 보여준다

그 내용형식이

1. 테이블 형식인 경우: 원본·추가 작업파일 구분 없이 CSV·XLSX를 테이블로 표시한다.
- 테이블은 우선 데이터 20행이 보이는 높이를 배정하고, 나머지 행은 내부 스크롤로 볼 수 있게 한다.
- 컬럼 수를 C, 전체 데이터 행 수를 R이라고 할 때, 원본 위에서부터 N = min(R, floor(5000 / C))행을 표시한다. 헤더와 화면상의 행 번호는 5,000셀 계산에서 제외한다.
- C 또는 R이 0이면 빈 테이블로 안내한다.
- 테이블 위에는 **현재 선택한 파일·시트의 전체 데이터 행 수와 컬럼 수**를 표시한다. N < R이면 이 텍스트 행 맨 앞에 **굵은 빨간색 [일부만]**을 붙인다.

컬럼헤드를 누르면 내림차순, 오름차순, 원래 순서 이렇게 전환되게한다(원본 위에서부터 N행을 가져오고, 그 N행 안에서만 정렬)

테이블너비는 웹화면 너비를 꽉 채우지 않는다.

2. md 파일인 경우 : 마크다운 반영해서 웹에 나오게
3. txt 파일인 경우 : 원문 그대로
4. 이미지인 경우 : 이미지 그대로
  5. PDF: 탭 안에서 원문 보기.
  6. PPTX: PPTX는 텍스트·이미지·도형·배치가 유지되는 슬라이드 미리보기로 표시한다. PDF 또는 슬라이드 이미지로 변환하는 방식을 허용한다. 변환 환경이 없으면 텍스트 미리보기로 임의 대체하지 말고 사용자에게 먼저 문의한다.
  7. HTML·HTM 파일은 탭 안에서 렌더링된 웹페이지로 표시한다. Plotly 차트 HTML은 확대·이동·마우스오버와 화면 크기에 따른 반응형 동작을 유지한다
  8. XLSX 여러 시트: 모든 시트를 열람할 수 있도록 시트 선택 제공.


메안 화면 내 탭 정렬 및 표시 규칙

- 원본 파일 탭은 항상 첫 번째에 배치한다.
- 추가 작업파일은 CSV·XLSX를 먼저 배치하고, 나머지 형식은 그 뒤에 배치한다.
- 같은 우선순위 안에서는 파일명 기준으로 정렬한다.

- 탭 버튼에는 확장자를 포함한 파일명만 표시한다.
- 폴더 경로와 "원본 ·", "추가 ·" 같은 접두어는 표시하지 않는다.


- 전체 경로는 마우스를 올렸을 때 툴팁으로 표시한다.
- 파일명이 중복되어도 실제 연결 경로는 각각 유지한다.

- 탭 글자 크기는 12px, 버튼 내부 여백은 상하 6px·좌우 10px로 한다.
- 탭이 한 줄에 들어가지 않으면 다음 줄로 배치한다





-웹디자인관련
좌측사이드바의 폴더구조에 파일목록을 보여줄때
csv.xlsx는 텍스트 배경색에 연한 초록색
ppt,pptx,pdf,docx는 텍스트 배경에 연한 빨간색
md.txt는 텍스트 배경에 연한 보라색
이미지는 텍스트 배경에 연한 노란색
좌측사이드바 폴더구조 상단에는 구조 모두펼치기, 접기 기능이있다, 기본은 모두 펼치기
사이드바 상태 유지: 파일을 선택하거나 새로 읽어도 사용자가 접어둔 상태 유지. 처음 열 때만 모두 펼침.
분석 결과가 없는 원본: 사이드바에서 제외하지 않고 원본 탭만 표시.

-라이브러리관련 규칙
Plotly 차트의 데이터와 상호작용을 유지한다.
탐색용 HTML을 생성할 때, 각 차트에 포함된 동일한 Plotly 라이브러리를 중복 저장하지 않는다. 차트 데이터·레이아웃·설정은 보존하고 공통 라이브러리는 한 번만 로드한다. 즉시보기용은 필요한 라이브러리까지 최종 HTML에 포함해 인터넷 없이 작동하도록 한다.




참고사항
* 본문 표시 방식이 정의되지 않은 파일 형식이 발견되면 HTML 생성 전에 사용자에게 문의한다. 사이드바 배경색만 지정된 PPT·DOCX 등도 표시 방식이 정해진 것으로 간주하지 않는다.

* 원본·분석 파일은 읽기만 하며, 분석 Python을 자동으로 재실행하거나 기존 입력 파일을 수정하지 않는다.

서버용은 ‘파일 다시 읽기’로 최신 파일을 반영한다.
즉시보기용은 생성 당시 데이터를 표시하며, 파일 변경 후에는 재생성해야 한다.
