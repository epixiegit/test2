# 연관 데이터 테스트 샘플

모든 인물·업체·거래는 테스트용 가상 데이터입니다. 실제 운영 자료가 아닙니다.
CSV는 UTF-8 BOM으로 저장했습니다. ID는 C001, O0001 등 접두사가 있는 문자열입니다.

## 파일 구성

- **고객.csv**: 40행, 7열
- **매장.csv**: 6행, 7열
- **직원.csv**: 18행, 7열
- **상품.csv**: 24행, 10열
- **주문.csv**: 60행, 10열
- **주문상세.csv**: 120행, 7열
- **배송.csv**: 45행, 7열

## 의도한 연결 관계

- `직원.csv.매장ID` → `매장.csv.매장ID`
- `매장.csv.관리자직원ID` → `직원.csv.직원ID`
- `주문.csv.고객ID` → `고객.csv.고객ID`
- `주문.csv.매장ID` → `매장.csv.매장ID`
- `주문.csv.직원ID` → `직원.csv.직원ID`
- `주문상세.csv.주문ID` → `주문.csv.주문ID`
- `주문상세.csv.상품ID` → `상품.csv.상품ID`
- `배송.csv.주문ID` → `주문.csv.주문ID`

## 확인할 항목

- [ ] 7개 CSV의 컬럼 분석과 차트가 생성되는지 확인
- [ ] 공통 ID를 기준으로 관계 후보가 나타나는지 확인
- [ ] 원본 표 미리보기에 샘플 표시가 보이는지 확인
- [ ] PPTX와 MD의 미지원 파일 처리 및 참고 문서 표시를 확인

## 데이터 규칙

- 각 테이블의 첫 번째 컬럼은 중복 없는 기본키입니다.
- 위 연결 관계에 미존재 참조 키는 없습니다.
- 주문 60개에 주문상세는 각 2개씩 있으며, 배송은 주문 중 45개에만 존재합니다.
- 배송중 5건은 배송완료일이 비어 있습니다. 결측치 분석 확인용입니다.
- 주문총액 = 주문상세 항목금액 합계 + 배송비 - 주문할인액입니다.
- 관계 분석기는 ID 이외 날짜·범주 등에서도 후보를 제시할 수 있으므로 이 문서의 의도한 관계와 대조하세요.
- 이 폴더에 파일만 생성했으며 분석 프로그램은 실행하지 않았습니다.
