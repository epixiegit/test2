# 디자인 공통폼

## 요청 예시

> 이 공통폼으로 [원하는 색상이나 분위기]의 디자인 지침을 만들어줘. 용도는 [사용할 곳]이야. 내가 정하지 않은 부분은 어울리게 채워줘. 가이드에 더 자세한 유저 요청이 필요한 경우 역질문해줘. 지침을 적용한 간단한 미리보기도 만들고, 화면을 보며 수정한 내용을 지침에도 반영해줘.

예를 들어 ‘파란색 라이트 테마, 한국어 업무 보고용’처럼 요청하면 된다. 색상은 개수 제한 없이 지정하거나 AI에게 맡길 수 있다. 아래 필요한 항목만 채우고, 사용하지 않는 항목은 생략한다.

---

# [테마 이름] 디자인 지침

## 1. 전체 방향

- 용도: [웹 화면 / PPT / 보고서 등]
- 누가 보는가: [자료를 볼 사람]
- 원하는 분위기: [차분함, 밝음, 전문적임 등]
- 가장 먼저 전달할 내용: [이 자료에서 제일 중요한 메시지]

## 2. 색상

- 기본 배경: [색상 코드]
- 본문 글자: [색상 코드]
- 주요 색상: [색상 코드와 사용할 곳]
- 추가 색상: [필요할 때만 색상 코드와 사용할 곳]
- 사용 원칙: [어디를 강조하고 어디는 차분하게 둘지]

## 3. 글꼴

- 사용할 글꼴: [한글 지원 글꼴과 없을 때 쓸 대체 글꼴]
- 제목: [크기·굵기]
- 본문: [크기·줄간격]
- 보조 설명: [크기·색상]

웹은 px/rem, PPT·보고서의 글자는 pt 등 매체에 맞는 단위를 쓴다.

## 4. 배치와 여백

- 기본 구성: [제목 → 요약 → 본문 등 읽는 순서]
- 바깥 여백: [수치와 단위]
- 내용 사이 간격: [수치와 단위]
- 정렬: [왼쪽 정렬, 숫자 오른쪽 정렬 등]
- 내용이 많거나 화면이 좁을 때: [줄바꿈, 세로 배치, 페이지 나누기 등]

## 5. 주요 요소

실제로 사용할 것만 간단히 정한다.

- 강조 영역: [핵심 수치·메모 등을 눈에 띄게 하는 방법]
- 표·차트: [사용할 경우 색상·정렬·강조 방법]
- 이미지: [사용할 경우 크기·비율·배치]
- 버튼·링크: [사용할 경우 모양·색상]
- 공통 모양: [모서리 둥글기·테두리·그림자 사용 여부]

## 6. 미리보기와 수정

- 실제 사용할 내용과 비슷한 분량으로 미리보기를 만든다. 긴 제목이나 표가 필요하다면 함께 넣는다.
- 핵심 내용이 먼저 보이는지, 글자가 잘 읽히는지, 잘리거나 겹치는 곳이 없는지 화면에서 확인한다. PPT는 슬라이드로, 인쇄물은 출력 형태로 확인한다.
- 화면을 보고 바꾼 색상·크기·간격은 이 지침에도 반영한다.
- 최종 지침에는 실제로 사용할 값과 규칙만 남긴다. 화면을 확인하지 못했다면 완료했다고 하지 않는다.
