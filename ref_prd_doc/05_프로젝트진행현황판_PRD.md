# 프로젝트 진행 현황판 PRD

- 유형: 보통 길이 PRD / 조직 내부용 신규 웹앱 / 첫 버전.
- 구성: 프론트엔드, 백엔드 API, DB, 로그인, 파일 업로드.
- 가상 프로젝트의 요구사항 예시.

## 개요
- 프로젝트별 담당자·일정·진행 상태를 모아 보는 웹앱.
- 첫 버전은 프로젝트와 작업의 기본 관리에 집중.

## 대상 사용자
- 조직원: 참여 프로젝트와 작업 관리.
- 프로젝트 관리자: 구성원과 프로젝트 설정 관리.
- 조직 관리자: 프로젝트 생성과 전체 조회.

## 화면
- 로그인 화면.
- 프로젝트 목록.
- 프로젝트 상세 및 작업 목록.
- 작업 상세.
- 프로젝트 구성원 관리.

## 요구사항
- 프로젝트 생성: 이름, 설명, 시작일, 종료 예정일.
- 구성원 추가·제거.
- 작업 등록: 제목, 담당자, 마감일, 상세 내용.
- 작업 상태 변경: 예정·진행 중·완료.
- 작업별 참고파일 업로드.
- 담당자·상태·마감일로 작업 필터.
- 완료되지 않고 마감일이 지난 작업 강조.

## 권한·업무 규칙
- 프로젝트 구성원과 조직 관리자만 프로젝트 상세 조회.
- 구성원은 작업 등록 가능.
- 작업 담당자와 프로젝트 관리자는 작업 내용·상태 수정 가능.
- 프로젝트에서 제거된 사용자는 이후 접근 불가.
- 담당자가 제거된 작업은 유지하고 담당자 재지정 필요 표시.

## 진행률 정의
- 완료 작업 수 ÷ 전체 작업 수 × 100.
- 작업이 없으면 ‘작업 없음’ 표시.
- 작업별 난이도와 소요시간 가중치는 적용하지 않음.

## 저장 정보
- 프로젝트, 구성원, 작업, 상태, 첨부파일 정보.

## 완료 기준
- 작업 상태 변경 후 진행률에 반영.
- 구성원 제거 후 화면과 API 양쪽에서 접근 차단.
- 파일 업로드 실패 시 작업 본문 유지 및 재시도 가능.

## 제외
- 간트차트, 공수 관리, 외부 고객 초대.
