# 업무 인수인계 관리 PRD

- 유형: 보통 길이 PRD / 조직 내부용 신규 웹앱 / 첫 버전.
- 구성: 프론트엔드, 백엔드 API, DB, 로그인, 파일 업로드.
- 가상 프로젝트의 요구사항 예시.

## 제품 개요
- 담당자 변경 시 업무 설명·파일·확인 상태를 관리하는 웹앱.

## 해결할 문제
- 문서를 전달해도 인수자가 확인했는지 알기 어려움.
- 업무별 미해결 사항과 참고파일 누락 가능.

## 사용자
- 인계자: 인수인계 내용 작성.
- 인수자: 내용 확인·질문·항목별 확인 처리.
- 팀 관리자: 담당자 지정·전체 상태 조회·최종 완료 처리.

## 기본 흐름
- 로그인 → 인수인계 건 생성 → 항목 작성 → 인수자 검토 → 미해결 사항 정리 → 관리자 완료 처리.

## 기능
- 제목, 인계자, 인수자, 목표 완료일 설정.
- 업무별 항목 등록.
  - 업무 설명.
  - 반복 주기.
  - 현재 진행 상황.
  - 주의사항.
  - 참고파일 업로드.
- 인수자가 항목별 확인 또는 보완 요청.
- 항목별 질문·답변 기록.
- 전체 확인 현황 표시.

## 업무 규칙
- 항목이 한 개 이상이고 모든 항목이 확인되어야 최종 완료 가능.
- 확인된 항목 수정 시 확인 상태 해제.
- 미완료 건에 새 항목 추가 시 해당 항목은 미확인 상태.
- 최종 완료 후 내용 수정 차단.
- 인계자 계정 비활성화 후에도 기록 유지.
- 비밀번호·인증키는 입력하거나 첨부하지 않도록 안내.
- 비밀정보는 조직의 별도 전달 절차 사용.

## 저장 정보
- 인수인계 건, 업무 항목, 첨부파일.
- 항목별 확인 상태와 확인자.
- 질문·답변과 변경 이력.

## 완료 기준
- 항목 수정 시 기존 확인 상태 해제.
- 미확인 항목이 있거나 항목이 없으면 완료 처리 차단.
- 인계자·인수자·담당 팀 관리자 외에는 접근 불가.

## 제외
- 외부 조직과 공유, 자동 문서 요약, 전자서명.
