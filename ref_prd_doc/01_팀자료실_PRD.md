# 팀 자료실 PRD

- 유형: 아주 짧은 PRD / 조직 내부용 신규 웹앱 / 첫 버전.
- 구성: 프론트엔드, 백엔드 API, DB, 로그인, 파일 업로드.
- 이 문서는 가상 샘플이며 요구사항은 실제 조직 환경에 맞게 조정.

## 목적
- 팀 문서가 여러 메신저에 흩어지는 문제 해결.
- 조직원이 한곳에서 자료를 올리고 검색할 수 있는 웹앱 제작.

## 사용자
- 일반 직원: 자료 등록·검색·다운로드.
- 관리자: 전체 자료 관리.

## 필수 기능
- 관리자가 등록한 계정으로 로그인.
- 제목·분류·설명을 입력하고 파일 업로드.
- 제목과 분류로 자료 검색 및 다운로드.
- 작성자는 본인 자료 삭제, 관리자는 전체 자료 삭제.

## 저장 정보
- 사용자, 자료 제목, 분류, 설명, 파일 정보, 작성자, 등록일.

## 완료 기준
- 업로드한 자료가 목록과 검색 결과에 표시.
- 로그아웃 상태에서는 목록 조회와 다운로드 차단.
- 삭제한 자료는 다운로드 불가.

## 제외
- 문서 공동 편집, 버전 관리.
