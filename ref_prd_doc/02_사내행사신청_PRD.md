# 사내 행사 신청 PRD

- 유형: 짧은 PRD / 조직 내부용 신규 웹앱 / 첫 버전.
- 구성: 프론트엔드, 백엔드 API, DB, 로그인, 파일 업로드.
- 정원 등 수치는 샘플용 가정값.

## 배경·목표
- 메신저로 참석 여부를 취합하면서 발생하는 명단 누락 방지.
- 행사별 신청과 취소를 웹에서 관리.

## 사용자
- 직원: 행사 조회·신청·취소.
- 운영자: 행사 등록·수정·신청자 확인.

## 주요 기능
- 조직 계정으로 로그인.
- 운영자가 행사명·장소·일시·정원·신청 마감일 등록.
- 행사 안내 이미지 또는 PDF 업로드.
- 직원이 행사 신청 및 신청 상태 확인.
- 정원 도달 시 추가 신청 차단.
- 마감 전까지 본인 신청 취소.
- 운영자가 신청자 명단을 CSV로 다운로드.

## 처리 규칙
- 한 사람은 같은 행사에 한 번만 신청 가능.
- 동시 신청 시에도 확정 인원은 정원을 초과할 수 없음.
- 취소한 자리는 다시 신청 가능.
- 신청자가 있는 행사는 삭제 대신 취소 상태로 변경.

## 저장 정보
- 사용자, 행사, 안내파일, 신청 내역과 신청·취소 시각.

## 완료 기준
- 정원 10명인 행사에 10명 신청 후 다음 신청 차단.
- 중복 신청으로 신청자 수가 증가하지 않음.
- CSV는 UTF-8 BOM으로 제공하고 Windows Excel에서 한글 정상 표시.

## 제외
- 대기자 자동 승급, 문자 발송.
