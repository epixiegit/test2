# 교육 수강·수료 관리 PRD

- 유형: 보통 길이 PRD / 조직 내부용 신규 웹앱 / 첫 버전.
- 구성: 프론트엔드, 백엔드 API, DB, 로그인, 파일 업로드.
- 가상 프로젝트의 요구사항 예시.

## 배경
- 교육 안내, 수강 신청, 수료 증빙을 따로 관리해 이수 여부 확인이 번거로움.

## 목표
- 교육별 신청자와 개인별 수료 상태 관리.
- 증빙 확인 후에만 수료 확정.

## 사용자
- 직원: 교육 신청·증빙 제출·본인 이력 조회.
- 교육 담당자: 교육 등록·증빙 검토·수료 확정.

## 핵심 기능
- 로그인.
- 교육명, 설명, 교육일, 신청 마감일 등록.
- 교육 안내파일 업로드.
- 마감 전 직원의 교육 신청·취소.
- 신청자가 수료증 PDF 또는 이미지 업로드.
- 담당자가 증빙 승인 또는 보완 요청.
- 직원별 수료 이력 검색.
- 교육별 신청·수료 현황 다운로드.

## 상태
- 신청 완료 → 증빙 제출 → 수료 확정.
- 증빙에 문제가 있으면 보완 요청.
- 보완 요청 상태에서는 증빙 재제출 가능.

## 저장 정보
- 교육, 신청 내역, 증빙파일, 검토 결과, 검토자, 검토일.
- 증빙 교체 이력과 이전 검토 결과 유지.

## 제약
- 다른 직원의 수료증은 일반 직원에게 비공개.
- 증빙 제출만으로 수료 처리하지 않음.
- 외부 교육사이트의 이수 여부 자동 확인 제외.

## 완료 기준
- 담당자 승인 전에는 미수료 상태 유지.
- 보완 요청 후 재제출 가능.
- 수료 현황 인원수와 다운로드 명단 인원수 일치.
- CSV 다운로드 시 UTF-8 BOM 적용.

## 미정 사항
- 수료증 보관 기간.
- 담당자의 수료 확정 취소 허용 조건.
