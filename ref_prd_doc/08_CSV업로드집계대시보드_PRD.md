# CSV 업로드·집계 대시보드 PRD

- 유형: 긴 PRD / 조직 내부용 신규 웹앱 / 첫 버전.
- 구성: 프론트엔드, 백엔드 API, DB, 로그인, 파일 업로드.
- 입력 형식과 집계 규칙은 샘플용 가정.

## 1. 목적
- 동일한 형식의 실적 CSV를 올리고 부서별·월별 결과 확인.
- 수작업 집계의 형식 오류와 중복 반영 방지.

## 2. 사용자
- 제출자: 담당 부서 데이터 업로드·검증·확정.
- 조회자: 권한이 있는 부서의 결과 조회.
- 관리자: 전체 데이터 조회·업로드 취소·권한 관리.

## 3. 첫 버전 범위
- 로그인 및 역할별 접근 제어.
- CSV 업로드·입력 검증·오류 행 확인.
- 집계 반영·기간 및 부서별 조회·결과 다운로드.

## 4. 입력 데이터
- 필수 열: 기준월, 부서코드, 항목코드, 실적금액.
- 기준월: YYYY-MM.
- 실적금액: 원 단위 정수, 음수 허용.
- 음수는 정정·차감 실적 표현에 사용한다는 가정.
- 허용 인코딩: UTF-8, UTF-8 BOM, CP949.
- 인코딩을 판별할 수 없으면 사용자가 인코딩을 선택하여 다시 검증.
- 해석 불가 파일은 확정 차단 및 변환 방법 안내.

## 5. 업로드 흐름
- 파일 선택 → 서버 검증 → 미리보기·오류 확인 → 사용자 확정 → 집계 반영.
- 검증 단계에서는 공식 집계에 반영하지 않음.
- 오류가 한 건이라도 있으면 전체 반영 차단.
- 오류 목록에 행 번호·열 이름·오류 사유 제공.

## 6. 중복·교체 규칙
- 동일 기준월·부서의 확정 데이터는 한 묶음만 유지.
- 한 파일은 하나의 기준월·부서 데이터만 포함.
- 기존 데이터가 있으면 교체 여부를 명시적으로 확인.
- 교체는 해당 월·부서 데이터 전체를 대상으로 수행.
- 교체 실패 시 기존 확정 데이터 유지.
- 원본 파일과 업로드 이력 별도 보관.

## 7. 조회 기능
- 월·부서·항목으로 필터.
- 실적 합계와 상세 행 표시.
- 반영된 원본 업로드 내역으로 이동 가능.
- 데이터가 없으면 0과 구분해 ‘데이터 없음’ 표시.

## 8. 저장 정보
- 업로드 원본과 파일명.
- 업로더·업로드 시각·검증 결과.
- 확정 데이터와 집계 대상 여부.
- 교체·취소 이력.

## 9. 품질 조건
- 금액은 소수점 오차 없이 집계.
- 화면·API·다운로드에 같은 필터 조건 적용.
- 확정 중 오류가 나면 일부 행만 반영되는 상태 방지.
- 오류 정보에 원본 행 번호 유지.
- 결과 CSV는 UTF-8 BOM으로 제공.

## 10. 완료 기준
- 검증용 데이터의 예상 합계와 화면 합계 일치.
- 잘못된 부서코드가 있는 파일은 확정 불가.
- 같은 월·부서 파일을 교체해도 금액 중복 합산 없음.
- 교체 중 실패 시 기존 결과 유지.
- 허용 인코딩의 한글 원본을 정상 해석.

## 11. 제외·미정
- 제외: 자유 형식 엑셀, 자동 데이터 정제, 실시간 외부 연동.
- 미정: 파일 최대 크기, 기준 처리시간, 원본 보관 기간.
- 미정 값은 실제 데이터 규모 확인 후 확정.
