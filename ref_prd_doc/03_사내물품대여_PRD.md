# 사내 물품 대여 PRD

- 유형: 짧은 PRD / 조직 내부용 신규 웹앱 / 첫 버전.
- 구성: 프론트엔드, 백엔드 API, DB, 로그인, 파일 업로드.
- 가상 프로젝트의 요구사항 예시.

## 목적
- 노트북·카메라 등 공용 물품의 보유 위치와 대여 상태 확인.

## 사용자
- 직원: 물품 조회·대여 요청·본인 대여 현황 확인.
- 관리자: 물품 등록·대여 승인·반납 처리.

## 기능
- 로그인.
- 관리자 물품 등록: 이름, 관리번호, 보관 위치, 설명, 사진 업로드.
- 대여 가능 물품 목록과 상세 화면.
- 직원이 사용 목적과 반납 예정일을 입력해 대여 요청.
- 관리자가 요청 승인 또는 반려.
- 관리자가 실제 물품 수령을 확인한 뒤 반납 완료 처리.

## 업무 규칙
- 물품 한 개에 활성 대여는 하나만 허용.
- 요청만으로 물품을 대여 중 상태로 변경하지 않음.
- 이미 대여된 물품의 다른 요청은 승인 불가.
- 반납 예정일이 지나면 연체 표시.

## 저장 정보
- 물품 정보와 보관 위치.
- 요청자·요청일·승인 상태.
- 대여일·반납 예정일·실제 반납일.

## 완료 기준
- 승인 시 물품 상태가 대여 중으로 변경.
- 반납 처리 후 대여 가능으로 변경.
- 동시 승인 요청에도 활성 대여는 하나만 생성.
- 일반 직원은 다른 사람의 요청 수정 불가.

## 제외
- 미래 날짜 예약, 연체료 계산.
