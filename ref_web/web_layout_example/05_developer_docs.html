GETTING STARTED / QUICKSTART

첫 문서를 생성해 보세요.

요청을 보내고, 응답을 확인하고, 원하는 방식으로 문서를 관리하세요. 기본적인 흐름을 세 단계로 살펴봅니다.

i
시작하기 전에

워크스페이스와 접근 키가 준비되어 있다고 가정합니다. 아래 코드는 문서 레이아웃을 위한 가상 API 예시입니다.

1

요청 인증 설정

요청 헤더의 Authorization에 접근 키를 전달합니다. 예시에서는 실제 키 대신 자리표시자를 사용합니다.

HTTP HEADERS예시 요청
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
2

새 문서 만들기

문서 제목과 내용을 담아 /v1/documents로 요청합니다.

POST /v1/documentsJSON
{
  "title": "프로젝트 시작하기",
  "content": "첫 번째 문서의 내용입니다.",
  "tags": ["guide", "onboarding"],
  "visibility": "workspace"
}
3

생성 결과 확인

생성된 문서의 고유 ID로 문서를 조회하거나 수정하는 흐름을 구성할 수 있습니다.

RESPONSE201 Created
{
  "id": "doc_sample_001",
  "title": "프로젝트 시작하기",
  "status": "created"
}
✓ DOCUMENT CREATED · 샘플 응답
