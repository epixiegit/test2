
# 공통 문서 작성 규칙

- 중요한 판단·결정, 재사용할 조사·검토 결과, 작업 재개·인계에 필요한 내용만 기록한다. 단순 질문이나 모든 대화를 매번 기록하지 않는다.

- 보고서는 역할표에 지정된 위치와 문서명을 사용한다. 전용폴더 경로는 프로젝트 루트 기준이며, 보고문서는 해당 전용폴더 안에 저장한다.

- 작성 전에 기존 보고문서의 관련 내용을 확인한다. 같은 내용을 반복하거나 동일한 목적의 문서를 불필요하게 추가 생성하지 않는다.

- 결론을 먼저 쓰고, 필요한 근거·출처, 미확인 사항, 다음 행동을 짧게 덧붙인다. 해당하지 않는 항목은 생략한다.

- 확인된 사실·가정·제안을 구분한다. 실제 실행·확인한 결과와 추정·테스트 제안을 구분한다.

- 특정 파일·코드 버전·조건에 대한 검토라면 대상과 기준 시점을 명시한다.

- 역할별 보고서의 의견은 제안으로 취급한다. 메인작업자는 채택한 결정과 이유를 프로젝트 상태 문서에 기록한다.

- 문서 생성·수정·삭제는 역할표의 권한을 따른다. 수정 전 사용자 확인이 필요한 역할은 기존 보고서에 내용을 덧붙일 때도 먼저 확인받는다.

- 보고서를 작성한 경우, 채팅 답변에 저장 경로와 핵심 결과를 짧게 알린다.
